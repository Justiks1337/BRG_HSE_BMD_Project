## Краткое описание проекта

Это проект туристических маршрутов по электричкам Москвы, реализованный при помощи Telegram бота на Python. 
Проект содержит несколько туристических маршрутов по выбору, а так же бинго по электричкам. 
Следуя по маршруту, пользователь открывает новые точки, пока не дойдёт до конца


## Правила проекта

- Каждый метод, файл и класс должен иметь docstring с подробной документацией
- Бизнес логика должна быть отделена от зависимостей (aiogram)


## Запуск тестов

- Не запускай тесты автоматически после каждой правки.
- Небольшие локальные изменения выполняй без запуска тестов,
  если пользователь явно не попросил проверку.
- Самостоятельно запускай тесты только для существенных
  изменений: реализации новой функциональности, переработки
  подсистемы или изменения нескольких связанных компонентов.
- Для таких изменений выбирай проверки, непосредственно
  связанные с задачей. Полный набор тестов запускай только
  при необходимости проверить влияние на весь проект.
- Не повторяй успешно пройденные проверки, если после них
  не было изменений, влияющих на результат.
- Если тесты не запускались, кратко укажи это в результате.

## Порядок работы

- До согласования разрешены чтение файлов, анализ
  и подготовка предлагаемого патча.
- Перед изменением файлов покажи пользователю
  предлагаемый unified diff и кратко объясни изменения.
- Применяй патч только после явной команды пользователя.
- Если после согласования нужны дополнительные изменения,
  покажи новый diff и дождись согласования.
- Сохраняй существующие изменения пользователя.
